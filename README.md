# 海带索引图 FILM

一个纯前端胶片索引图（contact sheet）生成器。把扫描后的单张底片图片整理为 135、半格、120 中画幅的索引图。图片只在浏览器本地处理，不上传服务器。

## 快速开始

### 1. 在线使用

访问：[https://judian99.github.io/film-index-generator/](https://judian99.github.io/film-index-generator/)

### 2. 下载 Release 压缩包

本项目是纯前端静态网页，无需安装依赖或运行构建命令。

1. 前往 [Releases 页面](https://github.com/Judian99/film-index-generator/releases)，下载最新版本的 ZIP 压缩包。
2. 将压缩包完整解压到本地文件夹。
3. 进入解压后的目录，用浏览器打开 `index.html`。

### 3. 使用 Git Clone

如需获取最新源码或参与开发，可以克隆仓库：

```bash
git clone https://github.com/Judian99/film-index-generator.git
cd film-index-generator
```

然后用浏览器打开 `index.html`。

### 使用方法

1. 打开页面时会显示欢迎页。点击"＋ 新建索引图"开始新项目；或在"历史项目"列表中点击已有项目继续编辑。
2. 点击"选择或拖入扫描件"，或直接把 JPG/PNG/WebP 文件拖入窗口。
3. 等待图片加载完成，自动生成索引图。
4. 使用侧栏调整排版、画幅和胶片外观；背景可选淡黄纸底、纯白或高斯模糊。
5. 点击"观片台"或按 `F` 进入沉浸检片模式。移动鼠标在整张索引上使用观片器，滚轮无极调节倍率（1X–60X）；左键单击切换聚焦/非聚焦模式，按 `Esc` 退出。触控设备可点按切换聚焦。
6. 点击"导出索引图"下载 PNG 或 JPG。导出弹窗可保持当前比例，也可选择 A4 竖向（1:√2）或横向（√2:1）；A4 模式会自动优化每行张数并居中扩展画布，不裁切照片。

观片器会放大整张索引内容（图片、齿孔、边字、片基与空白）。图片区直接读取裁切、旋转后的最终原分辨率画面，而不是放大预览图。通过百度网盘导入的照片会在首次稳定检视当前帧时按需获取原图。


## 项目管理

每次新建索引图都会创建一个独立项目，参数和图片来源自动保存到浏览器的 IndexedDB，关闭标签页后不会丢失。

- **历史项目**：欢迎页列出所有已保存的项目，显示张数和最后编辑时间，点击即可恢复。
- **项目名称**：顶部栏显示当前项目名，点击可内联重命名，按回车或点击其他区域提交。
- **切换项目**：点击顶部栏左侧的"☰"按钮回到欢迎页，选择其他项目或新建。
- **删除项目**：在历史项目列表中，点击项目卡片右侧的"删除"按钮。

### 重新打开项目时的文件读取

项目中保存的是文件来源信息，而非图片本身；重新打开时需要重新读取本地文件：

- **Chrome / Edge（推荐）**：通过拖拽方式导入的文件会保存文件系统句柄（File System Access API）。重新打开项目时，浏览器会自动从原始路径读取文件，弹窗询问权限后即可恢复；文件未移动或删除时，恢复成功率为 100%。
- **Firefox / 点击导入**：保存 File 对象引用，仅在当前浏览器会话内有效。关闭并重新打开浏览器后，图片无法自动恢复（参数和项目名称仍会保留）。

## 编辑单帧

在预览图的某一帧上右键，打开帧操作菜单。

<p align="center">
  <img src="docs/images/03-frame-menu.png" alt="帧操作菜单" width="680">
</p>

### 裁切

打开裁切弹窗，拖动四个角调整裁切区域，点击"应用裁切"确认。

<p align="center">
  <img src="docs/images/04-crop-editor.png" alt="裁切编辑器" width="680">
</p>

### 旋转

每点击一次将帧顺时针旋转 90°，支持多次旋转。

### 插入

在当前位置前插入一张空白帧，用于占位或标记。

### 导出单帧

在帧操作菜单中选择"导出单帧"，可将当前画面导出为独立的片基单帧图片。输出会沿用当前图片的裁切、旋转和方向处理，并使用当前索引的画幅、胶卷型号、边字、齿孔、宽幅成像覆盖设置以及排序后的帧号。

正式版仅提供片基单帧效果，不包含拍立得或幻灯片片夹样式。弹窗支持 PNG、JPG，以及 1x、2x、3x 和原图级输出；原图级仅支持 PNG。若原图级单帧超过浏览器画布上限，页面会提示改用 3x。

### 删除

从索引图中移除该帧。


## 胶卷型号

### 内置型号(缓慢更新)

提供常见胶卷型号下拉选择，每种型号包含名称、边字字样、冲洗工艺等预设信息。

### 自定义型号

在"自定义型号"面板中可新增、编辑、删除胶卷型号：

- **名称**：显示名称
- **边字字样**：出现在索引图边字区域，留空表示底片无边字
- **冲洗工艺**：C-41 彩色负片、黑白负片、E-6 反转片、ECN-2 电影卷
- **高级外观**：可自定义边字颜色、交替字样、帧号格式

自定义型号保存在浏览器 localStorage 中，支持 JSON 导入导出。

## 隐私说明

- 图片只在浏览器本地读取和绘制，不上传服务器
- 不写入额外元数据
- 项目数据（参数、文件来源）保存在浏览器 IndexedDB 中，自定义型号数据保存在 localStorage 中，清除浏览器数据会丢失
